# Nova Escape (โนวา เอส-เคฟ)

โครงงานวิชา 040613204 Object-Oriented Programming
ผู้จัดทำ: 6804062612323 นายธนภัจน์ ขนาบแก้ว (Section 1)

- **เล่นเกม:** ดาวน์โหลด [`NovaEscape.jar`](NovaEscape.jar) แล้วดับเบิลคลิก (ต้องมี Java 8 ขึ้นไป)
- **รายงาน:** [`docs/NovaEscape_Report.pdf`](docs/NovaEscape_Report.pdf)
- **Source Code:** โฟลเดอร์ [`src/`](src/novaescape)

เกม 2D ยานอวกาศ สู้กับยานต่างดาว เขียนด้วย Java Swing ล้วน ไม่ต้องติดตั้งไลบรารีเพิ่ม (ใช้ Java 8 ขึ้นไป)

กด **START** แล้วเลือกโหมด
- **CLASSIC:** หลบเลเซอร์ให้รอดในแต่ละตาตามโครงงานต้นฉบับ
- **ASSAULT:** ยิงสู้แบบ Metal Slug มี 3 ด่าน แต่ละด่านแมพ ศัตรู และบอสไม่ซ้ำกัน (เลือกด่านได้ หรือกด NEXT STAGE เล่นต่อเนื่อง)

## วิธีเปิดเกม
- **ดับเบิลคลิก `NovaEscape.jar`** เปิดเล่นได้ทันที (ต้องมี Java ในเครื่อง)
- **ดับเบิลคลิก `run.bat`** ใช้คอมไพล์โค้ดใหม่แล้วรัน (ต้องมี JDK) ให้ใช้ตัวนี้หลังแก้โค้ด
- **IntelliJ / Eclipse / NetBeans / VS Code:** เปิดโฟลเดอร์ `NovaEscape` ตั้ง `src` เป็น Source Root แล้วรัน `novaescape.Main`

## วิธีเล่น
| ปุ่ม | หน้าที่ |
|---|---|
| W / A / S / D | บังคับยาน ขึ้น / ซ้าย / ลง / ขวา (ใช้ลูกศรก็ได้) |
| Spacebar | ใช้ไอเทม (โล่ / โจมตี) ชิ้นที่ได้มาก่อน |
| เมาส์ | กดปุ่ม START, PAUSE, CONTINUE, เลือกไอเทม |
| 1 / 2 / 3 | เลือกไอเทมด้วยคีย์บอร์ดก็ได้ |

ขั้นตอนการเล่นในแต่ละตา
1. หลบเลเซอร์ให้ครบ 20 วินาทีจะได้ **WIN** แต่ถ้าชนเลเซอร์จะ **GAME OVER**
2. พอชนะจะมีให้เลือก **PAUSE** เพื่อหยุดเกมและสรุปคะแนน หรือ **CONTINUE** เพื่อเล่นต่อ
3. ถ้าเล่นต่อจะได้เลือกไอเทม 1 อย่าง แล้วตาถัดไปศัตรูจะยิงเร็วขึ้น ถี่ขึ้น ยิงทีละหลายเส้น และเล็งใส่เรามากขึ้น

ไอเทม
- **หัวใจ:** ถ้าโดนยิงจะชุบชีวิตให้ 1 ครั้ง ทำงานเองโดยไม่ต้องกด
- **โล่:** กด Space แล้วเป็นอมตะ 5 วินาที
- **โจมตี:** กด Space แล้วยานต่างดาวหยุดยิง 5 วินาที

คะแนนได้จาก (10 × เลขตา) ต่อวินาทีที่รอด บวกโบนัสผ่านตาอีก 100 × เลขตา คะแนนสูงสุดเก็บไว้ในไฟล์ `highscore.dat`

## โหมด ASSAULT (ยิงสู้แบบ Metal Slug)
| ปุ่ม | หน้าที่ |
|---|---|
| W / A / S / D | บังคับยาน |
| J หรือคลิกซ้าย (กดค้าง) | ยิง |
| K หรือคลิกขวา | Nova Bomb ลบกระสุนศัตรูทั้งจอ (ขณะขับรถถัง = ยิงปืนใหญ่) |
| เมาส์ | เล็งป้อมปืนรถถัง |
| Spacebar | ใช้ไอเทมในกระเป๋า (โล่ / EMP) |
| P หรือ ESC | หยุดเกมชั่วคราว |

**ลำดับหน้าจอ:** START → เลือกโหมด → ASSAULT → เลือกด่าน
- ตอนนี้เปิดให้เล่นได้ทุกด่าน
- จบด่านแล้วกด NEXT STAGE เพื่อเล่นต่อ คะแนน ชีวิต และระเบิดจะยกไปด่านถัดไป

### ด่าน 1: NOVA SECTOR
- **เขต:** Asteroid Belt → Alien Outpost → Debris Storm
- **ศัตรู:** Drone, Turret, Kamikaze, อุกกาบาต, มินิบอส Carrier
- **บอส MOTHERSHIP:** สู้ตรง ๆ หลบกระสุน
  - เฟส 1: ยิงเลเซอร์
  - เฟส 2: เรียกลูกน้อง + ยิงกระสุนเล็งเป้า
  - เฟส 3: กระสุนเกลียว + ลำแสงกวาด

### ด่าน 2: FROZEN RINGS (4 เขต)
- **เขต:** Ice Field → Crystal Rings → Glacier Fortress → Blizzard Pass
- **มินิบอส FROST WARDEN (เขต 3):** แกนคริสตัลที่มีโล่น้ำแข็ง 4 ชิ้นหมุนรอบตัว
  - โล่กันกระสุนทุกชนิด ต้องจับจังหวะยิงลอดช่องว่างระหว่างโล่ (แรงระเบิดจากจรวดหรือปืนใหญ่ยังโดนแกนได้)
  - เป็นระยะจะ Shard Storm กางโล่ออกกว้างแล้วหมุนเร็ว
  - เลือดต่ำกว่าครึ่ง: หมุนเร็วขึ้นและยิงวงกระสุน 8 ทิศ
- **กลไกพิเศษ:** พายุหิมะ (BLIZZARD) พัดยานถอยหลังเป็นระยะ ต้องฝืนบังคับไว้
- **ศัตรู:**
  - Shield Drone มีโล่ด้านหน้า กันกระสุนแนวนอน ต้องใช้ Spread / Laser / Rocket / ป้อมปืนรถถัง หรือยิงใส่โล่จนแตก
  - Ice Spinner ตายแล้วแตกเป็นเศษ 3 ชิ้น
  - Frost Bomber ทิ้งระเบิดน้ำแข็งที่แตกกระจาย 6 ทิศ
  - Frost Cannon ยิงลูกเยือกแข็ง ถ้าโดนยานจะช้าลง 2.5 วินาที
- **บอส CRYO SERPENT:** ยิงหัวเข้าเต็ม แต่ยิงโดนลำตัวที่เป็นเกราะเข้าแค่ 40% และชนลำตัวแล้วเจ็บ
  - เฟส 1: เลื้อยไปทั่ว + พ่นกระสุน + เข็มน้ำแข็งจากลำตัว
  - เฟส 2: มุดหายแล้วพุ่งตัดจอตามเลนที่มีแถบแดงเตือนก่อน
  - เฟส 3: + ฝนน้ำแข็งตกจากด้านบน

### ด่าน 3: HIVE CORE (6 เขต)
- **เขต:** Hive Mouth → Brood Nest → Core Veins → Acid Grotto → Nerve Cluster → Queen's Passage
- **เขต Acid Grotto:** มีกรดหยดลงมาจากเพดานตลอดทาง
- **มินิบอส BROOD MOTHER (เขต 4):** เกาะเพดานหรือพื้น แล้วไต่สลับข้างเป็นระยะ ตอนกำลังข้ามจะลอยกลางจอ ยิงง่ายที่สุด
  - ท่าโจมตี: พ่นกรดเป็นวิถีโค้ง, วางไข่บนผนัง, ปล่อยตัวอ่อน
- **เขต Nerve Cluster:** มีระลอก ELITE GUARDS เป็น Hive Guard 3 ตัวพร้อมกัน
- **กลไกพิเศษ:** อุโมงค์ผนังเนื้อเยื่อบีบเข้ามา ชนผนังแล้วเจ็บ กระสุนศัตรูชนผนังแล้วหาย (กระสุนเราทะลุผนังได้)
- **ศัตรู:**
  - Spore Pod ติดผนัง ปล่อยสปอร์ไล่ตาม (มอนติดผนังยื่นออกมาและมีกล่องชนใหญ่ ยิงโดนง่าย)
  - Egg Sac เข้าใกล้แล้วฟักตัวอ่อน
  - Larva ตัวอ่อนไล่กัด
  - Hive Guard เกราะหนา พ่นกรด และพุ่งชาร์จ
- **บอส HIVE QUEEN:** ตัวราชินียิงไม่เข้า ต้องทำลายตา 3 ดวงก่อน หัวใจถึงจะเปิดให้ยิง
  - ตลอดการต่อสู้: ฟาดหนวดตามเลน (มีแถบเตือน) + ปล่อยตัวอ่อน
  - ช่วงสุดท้าย: + ฝนกรด + วงกระสุน

### รถถัง NOVA SLUG (มีด่านละ 1 คัน)
- **การขึ้นรถ:** จอดรออยู่กลางด่าน มีป้าย GET IN! และจุดสีเหลืองบนแผนที่ HUD บินไปชนเพื่อขึ้น
- **ปืนกล:** ป้อมปืนหมุนเล็งตามเมาส์ 360°
- **ปืนใหญ่:** กด K ยิงปืนใหญ่ระเบิด ไม่เสียลูกระเบิดของเรา
- **เกราะ:** มีเกราะ 12 ช่องรับดาเมจแทนคนขับ เก็บ Medkit ได้ +4
- **เก็บกล่องปืนตอนอยู่ในรถ:** เพิ่มเวลารถ +1 วินาที สะสมได้สูงสุด 35 วินาที และปืนนั้นเก็บไว้ใช้หลังลงจากรถ (มีตัวอักษรปืนโชว์ข้างเวลาใน HUD)
- **เวลา:** ใช้ได้ 25 วินาที หมดเวลาหรือเกราะแตกจะดีดตัวออก และรถจะระเบิดใส่ศัตรูรอบ ๆ
- **ถ้าบินผ่านไปไม่ขึ้น:** อดใช้ในรอบนั้น

### ความสมดุล (แก้ได้ที่ `assault/Balance.java`)
- **ระเบิด:**
  - เริ่มด่านมี 2 ลูก ถือได้สูงสุด 6 ลูก เก็บกล่อง B ได้ครั้งละ +1
  - ดาเมจศัตรูทั่วไป 10 / บอส 12 และต้องรอ 1 วินาทีก่อนกดลูกต่อไป
  - ยังลบกระสุนศัตรูทั้งจอได้เหมือนเดิม
- **ความยากตามด่าน:**
  - เลือดศัตรูทั่วไป ×1.0 / ×1.25 / ×1.5
  - ความเร็วกระสุนศัตรู ×1.0 / ×1.1 / ×1.2
  - Medkit ดรอป 9% / 6% / 4%
  - โอกาสมอนทั่วไปดรอปของ ×0.5 / ×0.4 / ×0.33 (มินิบอส ตัวประกัน และกล่องเสบียงไม่โดนคูณ)
- **บอส:**
  - Mothership: 420
  - Cryo Serpent: 360 (ยิงหัวเข้าเต็ม ลำตัวเข้า 40%)
  - Hive Queen: ตา 3×100 + หัวใจ 220
- **ท่าใหญ่ของบอส:** ลำแสง, หนวด และงูพุ่งตัดจอ โดนแล้วเสีย HP 2 ช่อง
- **ด่าน 2–3 ตอนบอสเปลี่ยนเฟส:** ดรอปปืน 1 อันต่อเฟส สุ่มจากปืนที่ไม่ใช่ปืนที่ถืออยู่ และเกิดในระยะที่เก็บได้
- **อุโมงค์ด่าน 3:** ผนังหนาสุดข้างละประมาณ 100 px ช่องบินกว้างอย่างน้อยประมาณ 290 px แก้ได้ที่ `depth()` ใน `Stage3HiveCore.java`

### ทั่วไป
- **ห้องบอส:** กล้องซูมออกให้เห็นพื้นที่กว้างขึ้นประมาณ 25%
- **อาวุธ:** H = Heavy MG, S = Spread, L = Laser (ทะลุ), R = Rocket (ติดตามเป้า)
- **ไอเทม:** Bomb +1, Medkit, Shield, EMP, 1UP, Gem
- **นักบินอวกาศ (HELP!):** บินไปชนเพื่อช่วย ได้ +500 และไอเทม 1 ชิ้น ตอนจบด่านได้โบนัสเพิ่มอีกคนละ 1,000
- **ชีวิต:** HP 5 ช่อง + ชีวิตสำรอง
- **คะแนนสูงสุด:** เก็บใน `highscore_assault.dat`

## เสียง
- **ปุ่ม M:** เปิด/ปิดเสียงได้ทุกหน้าจอ ตอนปิดจะมีป้าย "SOUND OFF [M]" ที่มุมขวาล่าง
- **สร้างด้วยโค้ดทั้งหมด:** ไม่มีไฟล์เสียงในโปรเจกต์ (อยู่ในแพ็กเกจ `audio/`)
- **เพลงประกอบ (8-bit):** แยกเป็นเพลงเมนู, โหมด CLASSIC, ด่าน 1, ด่าน 2, ด่าน 3 และเพลงบอส
- **เอฟเฟกต์:**
  - ปืนแต่ละแบบเสียงไม่ซ้ำกัน, กระสุนศัตรู, ระเบิดเล็ก/ใหญ่
  - โดนยิง, โดนแช่แข็ง, เก็บของ, 1UP, ช่วยนักบินอวกาศ
  - Nova Bomb, EMP, โล่, ขึ้นรถถัง, ปืนใหญ่
  - เตือนบอส, บอสคำราม, GO!, ชนะ, Game Over, จบภารกิจ
- **ปรับเสียง:**
  - ความดังรวมกับความดังเพลง: แก้ `MASTER_VOLUME` / `MUSIC_VOLUME` ใน `audio/Sound.java`
  - ความดังของแต่ละเสียง: แก้ตารางบนสุดของ `audio/Sfx.java`
  - ทำนอง จังหวะ และคอร์ดของเพลง: แก้ใน `audio/Music.java`
- **เครื่องไม่มีลำโพงหรือการ์ดเสียง:** เกมยังเล่นได้ปกติ แค่ไม่มีเสียง

## จะเพิ่มฟีเจอร์ แก้ตรงไหน
- **ปรับความยาก / เวลาต่อตา:** แก้ที่ `Config.java` และ `Difficulty.java`
- **เพิ่มไอเทมใหม่:** เพิ่มค่าใน `ItemType` แล้ววาดไอคอนใน `drawIcon()` จากนั้นใส่ผลของไอเทมใน `GamePanel.useItem()`
- **เปลี่ยนรูปยานเป็นไฟล์ภาพ:** แก้เมธอด `draw()` ใน `PlayerShip` / `AlienShip` ให้ใช้ `g.drawImage(...)` แทน
- **ศัตรูแบบใหม่ / อุปสรรคแบบใหม่:** สร้างคลาสใหม่ใน `entity/` แล้วเรียก `update` / `draw` ใน `GamePanel`
- **(ASSAULT) แก้ด่าน / ย้ายศัตรู / เพิ่มระลอกใหม่:** แก้เมธอด `build()` ในไฟล์ `stage/StageN...java` โดย `L.at(x, ...)` = เกิดเมื่อกล้องถึงตำแหน่ง x และ `L.lockAt(x, ...)` = ล็อกกล้องจนกว่าจะฆ่าหมด
- **(ASSAULT) เพิ่มด่าน 4:** สร้างคลาส `extends Stage` แล้วเพิ่มใน `Stage.create()` และแก้ `Stage.COUNT`
- **(ASSAULT) ปรับรถถัง:** `NovaSlug.TIME_LIMIT` (เวลา), `MAX_ARMOR` (เกราะ), ตำแหน่งจอดแก้ที่ `vehicleX()` ของแต่ละด่าน
- **(ASSAULT) ปืนใหม่:** เพิ่มค่าใน `Weapon` + เขียนการยิงใน `fire()` + เพิ่มชนิดใน `Pickup.Kind`
- **(ASSAULT) ศัตรูใหม่:** สร้างคลาส `extends Enemy` ใน `assault/enemy/` แล้วเรียก `g.spawn(...)` ใน `Level`
- **(ASSAULT) ปรับบอส:** แก้ `MothershipBoss` / `CryoSerpentBoss` / `HiveQueenBoss` (HP อยู่ที่ `MAX_HP` / `HEART_HP` และการโจมตีแยกตามเฟส)
- **หน้าจอใหม่:** เพิ่มค่าใน `GameState` แล้วเพิ่มเมธอด `drawXxx()` และ `case` ใน `update()` / `paintComponent()`
